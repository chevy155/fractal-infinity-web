Why this exists

The final answer hides the process.

Modern AI systems can use multiple agents, tools, searches and sources while producing one polished final answer.

The answer alone does not show whether those processes added independent evidence or simply repeated the same information.

Fractal records observable research activity and produces an X-Ray of the process behind the answer.

How to test

Connect → research normally → open the X-Ray cold.

  1. Connect Fractal Process Intelligence to an MCP-compatible AI client.
    https://mcp.fractalinfinity.io/mcp
  2. Start a new research conversation.
  3. Tell the AI to use Fractal for the investigation (copy the block below).
  4. Ask your normal research question.
  5. Read the AI's final answer first.
  6. Open the Fractal X-Ray URL.
  7. Ask: “What did the X-Ray reveal that I would not have known from the final answer alone?”

Copyable instruction for the AI

Use Fractal Process Intelligence to record this research run.

Record the participating agents, meaningful sources, important claims,
uncertainty, disagreement and significant tool usage.

Finish the run and return the Fractal X-Ray URL.

Do not interpret the X-Ray for me before I open it.

Windows / Claude Desktop

Alpha setup (current testing method)

This is the current testing path — not final onboarding. Do not overwrite other existing Claude configuration; merge the MCP entry.

Show Claude Desktop config steps
  1. Claude Desktop → Settings → Developer → Edit Config
  2. Add the MCP server entry below (preserve other keys).
  3. Save.
  4. Fully quit Claude Desktop (system tray → Quit).
  5. Reopen Claude.
  6. Settings → Developer should show fractal-process-intelligence running.
{
  "mcpServers": {
    "fractal-process-intelligence": {
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.fractalinfinity.io/mcp"
      ]
    }
  }
}

Microsoft Store Claude may store this under the package LocalCache path. Prefer Edit Config from Claude so the correct file opens. Use the full npx.cmd path on Windows.

FAQ

Want to use Claude normally?

Leave Fractal installed. Fractal does not automatically record every Claude conversation.

For a normal conversation, do not start a Fractal run and do not invoke its recorder tools. Where Claude exposes per-conversation tool/connector controls, you may also disable Fractal for that conversation.

Fractal records research only when its tools are explicitly used.
